一个脚本，把 Windows 变成能跑 AI 编程的 Linux 开发机

主力机是 Windows，又想要 Linux 命令行、又馋 AI 编程的，看这条

我做了个开源项目：从一台裸 Win11 开始，一条命令装到能用
WSL2 + Ubuntu + Claude Code + DeepSeek 全打通

📌 能拿它干嘛

· 写脚本、跑 Python/Node，不用再开笨重的虚拟机，启动一两秒
· 终端里直接让 AI 读代码、改 bug、写测试、生成文档
· 练 Linux、装 Docker 和数据库，搞崩了删掉重装几分钟，Windows 本体一点事没有
· VS Code 装个插件就能编辑 WSL 里的文件，和本机开发没区别

💡 比自己照教程装好在哪

· 一键验证，不用靠猜"到底装好没有"
· 脚本可以重复跑，环境崩了重跑一遍就恢复
