📦 这个仓库给你什么

四个阶段全脚本化，不是让你对着教程手敲：

1. 启用 WSL2 + 安装 Ubuntu（设为默认发行版）
2. 装 Node.js LTS + Claude Code CLI
3. 把 DeepSeek API 接进去 —— base url 和模型名都是我实际发请求验证过能跑通的，不是照抄文档
4. 一条命令自动验证全流程

配置文件里 API Key 是占位符，填自己的就行（.gitignore 已经帮你挡住密钥，不会误提交）。

💡 和网上教程最大的区别

市面教程基本只讲"顺利的情况"。我这份记录的是真实翻车过程，每个坑都有根因和修法：

· 微软商店 CDN 被墙 → wsl --update 直接 403，脚本改成「本地 MSI → GitHub 下载 → 官方 CDN」三级回退
· wsl.exe 只装了个 inbox stub → 一直提示"必须更新到最新版本"
· 注册表残留孤儿登记 → 显示已安装但目录根本不存在，装不上也删不掉
· PowerShell 脚本写中文 → 被按 GBK 读取，直接 ParserError
· .sh 被转成 CRLF → 在 Ubuntu 里报 bad interpreter

README 里写得很细，446 行，属于"照着做就能成"的那种。
